# DH-Tools (Death Happens Dev)

Addon source for **DH-Tools**, the Death Happens guild's WoW Classic Era Hardcore toolkit (Air Service, Bavin, Danger, Quests, Macros, Mob Marker).

**⚠️ Read [CONTRIBUTING.md](./CONTRIBUTING.md) before touching any code.** It covers the workflow (branch → test → PR) and a short list of places where a small, well-meaning change can quietly break something in an actual Hardcore run.

Questions before you start? Ask in Discord first.
